# Playlist Studio tasarım kaynağı

Uygulamanın düzenlenebilir masaüstü arayüzü Figma'da tutulur:

- [Playlist Studio — Windows Desktop App](https://www.figma.com/design/Gr7dOeFifG3j7D6mgY1FjR)
- Yeni indirme ekranı: `5:2`
- İndirmeler ve durum örnekleri: `5:51`
- Sistem durumu ekranı: `5:119`

Dosyada renk, boşluk ve köşe değişkenleri; yazı stilleri; düğme, gezinme öğesi,
durum etiketi, URL alanı ve panel bileşenleri bulunur. Starter planındaki üç sayfa
sınırı nedeniyle temel öğeler, bileşenler ve ekranlar üç sayfada düzenlenmiştir.

`assets/playlist-studio-mark.svg`, uygulama içinde ve paketleme sırasında
kullanılabilen düzenlenebilir kaynak logodur.

Higgsfield ile özel görsel üretimi denendi; hesap planı Basic veya üstü olmadığı
için servis üretimi başlatmadı. Bu nedenle logo şimdilik projeye ait düzenlenebilir
vektör kaynaktır.
